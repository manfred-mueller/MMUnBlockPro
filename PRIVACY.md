# Datenschutzerklärung / Privacy Policy – MMUnblock Pro

**Stand:** Oktober 2026 · **Anbieter:** Manfred Müller (Open Source Developer), mail@manfred-mueller.org

## Deutsch
MMUnblock Pro erhebt, speichert und übermittelt **keine personenbezogenen Daten** an den Entwickler oder Dritte. Es gibt keine Telemetrie, keine Analyse, keine Werbung und keine Verbindung zu externen Servern.

- Wenn ein Download abgeschlossen ist, liest die Erweiterung lokal den Dateipfad und die Herkunfts-Domain des Downloads, um zu entscheiden, ob die Datei entsperrt werden soll.
- Der Dateipfad wird ausschließlich per Native Messaging an die lokal installierte Komponente `mmunblockhost.exe` auf Ihrem Computer übergeben, die den Zonenmarker (Zone.Identifier) der Datei entfernt.
- Die von Ihnen eingetragene Domain-Whitelist wird nur lokal im Browser (`storage.local`) gespeichert.

## English
MMUnblock Pro does **not collect, store or transmit personal data** to the developer or any third party. There is no telemetry, analytics, advertising or connection to external servers.

- When a download completes, the extension locally reads the file path and the source domain to decide whether the file should be unblocked.
- The file path is passed only via Native Messaging to the locally installed component `mmunblockhost.exe`, which removes the file's Zone.Identifier (Mark of the Web).
- The domain whitelist you enter is stored locally in the browser only (`storage.local`).
